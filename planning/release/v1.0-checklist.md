# v1.0.0 — Critérios de Consolidação e Release

> Checklist da futura **v1.0.0**, primeira release oficial planejada para a linha atual do HomeServer.
>
> **Status atual:** não iniciado como processo de release.
>
> Este documento não indica que a publicação está próxima. Ele registra os critérios que deverão ser reavaliados quando houver uma decisão explícita de consolidar e publicar a primeira versão oficial.

Critérios gerais: [`definition-of-ready-for-release.md`](definition-of-ready-for-release.md)  
Processo: [`release-process.md`](release-process.md)

## Política atual

Até existir uma decisão explícita de iniciar a consolidação da `v1.0.0`:

- não criar Tags intermediárias apenas para marcar progresso;
- não criar GitHub Releases intermediárias;
- continuar usando commits, branches, documentação, testes e validação prática;
- tratar evidências antigas como históricas, não como aprovação automática do estado futuro;
- permitir refatorações e mudanças de planejamento quando justificadas por uso real.

## Evidências históricas

O projeto possui evidências anteriores de testes, hardening, instalação e outras validações registradas em documentos de planejamento e auditoria.

Essas evidências continuam úteis para:

- identificar o que já foi testado;
- comparar regressões;
- reduzir retrabalho;
- orientar a validação futura.

Elas não tornam automaticamente a `v1.0.0` pronta. Os critérios relevantes deverão ser reavaliados no estado final que será candidato à primeira release oficial.

## Início do processo de release

Este checklist só deve mudar para estado ativo quando houver uma decisão explícita equivalente a:

> O escopo da primeira versão oficial está definido e o projeto entrará em fase de consolidação para a `v1.0.0`.

A partir desse momento:

```text
Definir escopo final
        ↓
Corrigir bloqueios
        ↓
Executar testes
        ↓
Validar no ambiente real
        ↓
Freeze
        ↓
Aprovação final
        ↓
Tag v1.0.0
        ↓
GitHub Release v1.0.0
```

Até essa decisão, o documento permanece como referência futura e não como um contador de progresso obrigatório.
