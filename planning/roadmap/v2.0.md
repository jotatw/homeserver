# HomeServer v2.0 — Roadmap

> A v2.0 é a próxima grande versão. Toda implementação é lançada como
> release (tag `vX.Y.Z`) e distribuída via GitHub + Gitea, com o sistema
> de auto-update (`hs update check|apply`) já disponível na v1.3.0.

## Releases atuais

| Versão | Data | Conteúdo |
|--------|------|----------|
| v1.0.0 | — | Fundação e módulos iniciais |
| v1.1.0 | — | Homepage + storage + serviços |
| v1.2.0 | 2026-08-03 | Unified Access (Caddy, HTTPS, homeserver.local) |
| v1.3.0 | 2026-08-04 | Autenticação, proteção de rotas, App com login, auto-update, fix religamento (S3) |

## Pré-requisito da v2.0

- [x] Sistema de releases por tag (`vX.Y.Z`)
- [x] Publicação automática no GitHub e Gitea
- [x] Auto-update no CLI (`hs version`, `hs update check`, `hs update apply`)
