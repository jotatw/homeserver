# HomeServer v2.0 — Roadmap

> A v2.0 é a próxima grande versão da plataforma. A linha v1.x continua recebendo correções e pequenas melhorias compatíveis enquanto a v2.0 é preparada.

## Linhas de desenvolvimento

| Linha | Objetivo |
|---|---|
| v1.x | Correções, pequenas melhorias e manutenção da plataforma existente |
| v2.0 | HomeServer App e evolução para uma plataforma integrada |
| v2.x | Evolução do App, integrações e automações posteriores |

Toda implementação relevante é lançada como release (`vX.Y.Z`) e distribuída via GitHub + Gitea, com o sistema de auto-update (`hs update check|apply`).

## Pré-requisitos da v2.0

- [x] Sistema de releases por tag (`vX.Y.Z`)
- [x] Publicação automática no GitHub e Gitea
- [x] Auto-update no CLI (`hs version`, `hs update check`, `hs update apply`)
- [x] Homepage consolidada como portal (v1.4)
- [x] Design System definido (v1.4.5)
- [x] Foundation estável (v1.5.0: code review, segurança, ADRs, testes, Quality Gate)
- [x] App Design definido (branch `app-design`: referências, wireframes, fluxos, tokens, componentes)

## Release Candidate

A RC da v2.0 cobre os Sprints 0–7. Após a RC, somente correções, documentação, testes e CI entram na linha da release. Novas funcionalidades ficam para versões posteriores.

## Regra de evolução

Toda nova versão começa com um Health Survey (check-up do estado atual). A linha v1.x pode continuar recebendo correções e pequenas melhorias compatíveis sem alterar o escopo arquitetural definido para a v2.0.
