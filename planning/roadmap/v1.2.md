# HomeServer v1.2 — Unified Access

> **Unified Access — Um único ponto de entrada para todo o HomeServer.**

## Objetivo

Esconder a infraestrutura: o usuário nunca vê portas nem endereços IP.

```text
homeserver.local/
    ├── /        → Homepage
    ├── /files   → FileBrowser
    ├── /git     → Gitea
    └── /api     → API
```

Path-based (sem subdomínios) para reforçar a identidade de **um único
sistema**, não serviços separados.

## Entregas

### Módulo Caddy

- `modules/caddy/` como módulo oficial:
  - `compose.yaml`
  - `Caddyfile` (rotas path-based)
  - `.env.example` (porta, domínio)

### Resolução local (mDNS)

- `avahi-daemon` para `homeserver.local` na LAN.
- Descoberta automática, sem configurar cada dispositivo.

### Ajustes na Homepage

- Hrefs de `http://192.168.1.10:3000|8080|3001|8000` → `/`, `/files`, `/git`, `/api`.
- Widgets Custom API continuam internos (`http://api:8000`) — não passam pelo proxy.

### UFW

- Liberar 80/443 (proxy) na rede local.

### Documentação

- Seção "Acesso unificado" no README.
- Atualizar `planning/backlog/completed.md`.

## Fora de escopo (v2.x)

- **VPN** (Tailscale/WireGuard) — acesso externo fica para versões futuras.
- Exposição à internet — não será feita.

## Resultado esperado

- `homeserver.local` resolve na LAN.
- Todos os serviços acessíveis por caminhos limpos.
- O usuário interage apenas com o HomeServer, sem conhecer portas.
