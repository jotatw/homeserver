# HomeServer v1.2 — Unified Access

> **Status: HISTÓRICO.** Documento de planejamento da evolução de acesso unificado.

## Objetivo

Esconder a infraestrutura: o usuário não precisa conhecer portas nem endereços IP.

```text
homeserver.local/
    ├── /        → Homepage
    ├── /files   → FileBrowser
    ├── /git     → Gitea
    └── /api     → API
```

Path-based, sem subdomínios, para reforçar a identidade de um único sistema.

## Entregas

### Módulo Caddy

- `modules/caddy/` como módulo oficial;
- `compose.yaml`;
- `Caddyfile`;
- `.env.example`.

### Resolução local (mDNS)

- `avahi-daemon` para `homeserver.local` na LAN;
- descoberta automática.

### Ajustes na Homepage

- Hrefs de portas/IP para `/`, `/files`, `/git` e `/api`;
- widgets Custom API permanecem internos (`http://api:8000`).

### UFW

- liberar 80/443 para o proxy na rede local.

- seção "Acesso unificado" no README;
