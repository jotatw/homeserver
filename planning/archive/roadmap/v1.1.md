> **Objetivo**: Refinar a experiência do usuário sem alterar a arquitetura do sistema.
>
> **Status: HISTÓRICO.** Este documento é preservado como registro da evolução anterior.

> **Regra**: cada sprint deve entregar algo que o usuário perceba imediatamente ao abrir a Homepage.

## Sprint 1 — Homepage Refinement

### Epic HS-101 — Storage `NaN` (Correção)

- **Problema**: card Storage mostra `NaN`.
- **Causa**: `format: size` do widget `customapi` retorna `NaN` para números.
- **Correção**: API retorna contagens; card usa `format: number`.
- **Verificação**: sem `NaN`; valores consistentes.

### Epic HS-102 — Bookmarks `undefined URL` (Correção)

- **Problema**: `TypeError: URL constructor: undefined` no console.
- **Causa**: bookmarks sem `description` disparam `new URL`.
- **Correção**: `description` em todos os bookmarks.
- **Verificação**: console limpo.

### Epic HS-103 — Links e ícones (Correção)

- Revisão de `href`, ícone, título, descrição e destino de todos os cards/bookmarks.
- Ícones `mdi-*`/`sh-*` dependem de CDN; robustez offline fica no backlog.

### Epic HS-104 — Card Storage (Melhoria)
