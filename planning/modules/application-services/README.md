# Application Services

## Objetivo

Agrupa serviços disponibilizados aos usuários pela plataforma, priorizando integração consistente com o App e independência entre contrato e implementação.

## Módulos previstos

- Homepage / Hub;
- serviços de arquivos;
- Git e serviços de desenvolvimento doméstico;
- aplicações futuras instaláveis como módulos.

## Princípios

Cada serviço deve poder ser instalado, configurado, iniciado, parado, atualizado e removido segundo contratos comuns, sem exigir que o usuário utilize o terminal para operações cotidianas.

## Integrações

Entradas do App, rotas e atalhos são integrações com lifecycle próprio. O módulo não deve ser confundido com sua representação na interface.

## Estado

Planejamento funcional fechado. O catálogo final de aplicações poderá crescer sem alterar as regras do grupo.
