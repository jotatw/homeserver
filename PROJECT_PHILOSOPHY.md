# Filosofia do Projeto

## Missão

Construir uma plataforma pessoal modular, reproduzível e de fácil manutenção.

## Objetivos

- Aprender.
- Documentar.
- Automatizar.
- Compartilhar conhecimento.

## Princípios

- Funcional antes de completo.
- Simples antes de complexo.
- Automatizar somente depois de entender.
- Tudo deve ser reproduzível.
- Infraestrutura como código.
- Dados separados da infraestrutura.
- Toda decisão importante deve ser documentada.

## Visão

Que um novo servidor possa ser reconstruído apenas com:

- o repositório Git;
- os backups de `/srv/data`;
- alguns comandos.
