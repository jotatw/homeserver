# HomeServer

Servidor doméstico baseado em Debian 13.

## Hardware

- Equipamento: MSI MS-AA1511
- CPU: Intel Pentium Dual-Core T4500
- RAM: 3 GB
- Disco: 320 GB HDD

## Sistema Operacional

- Debian 13 (Trixie)

## Objetivos

- Compartilhamento de arquivos (Samba)
- Servidor Git (Gitea)
- Gerenciamento de arquivos (FileBrowser)
- Containers Docker
- Backup automatizado
- Monitoramento básico

## Estrutura

- Docker
- Portainer
- Samba
- FileBrowser
- Gitea
