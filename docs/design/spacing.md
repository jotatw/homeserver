# Espaçamento

Escala base de espaçamento (múltiplos de 4px).

## Tokens

| Token | Valor | Uso |
|-------|-------|-----|
| `space-1` | 0.25rem (4px) | Gap mínimo entre ícone e texto |
| `space-2` | 0.5rem (8px) | Padding interno pequeno, gap de chips |
| `space-3` | 0.75rem (12px) | Padding interno padrão de cards |
| `space-4` | 1rem (16px) | Padding de cards, gap de grids |
| `space-6` | 1.5rem (24px) | Espaço **entre grupos** |
| `space-10` | 2.5rem (40px) | Margem antes do rodapé |

## Regras

- **Entre grupos**: `1.5rem` (espaço maior para separar categorias).
- **Dentro dos cards**: `0.75rem` (compacto, menos ruído).
- Header da página: padding vertical `0.5rem` (compacto).
- Rodapé: `1rem` acima do border, `1.5rem` abaixo.

## Cards

| Grupo | Padding | Raio de borda | Sombra |
|-------|---------|---------------|--------|
| Meu espaço (principal) | 1rem | 12px | sim (destaque) |
| Aplicações / Administração | 0.9rem | 10px | leve |
| Sistema (técnico) | 0.75rem | 8px | nenhuma |
