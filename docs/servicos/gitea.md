# Gitea

## Objetivo

Servidor Git auto-hospedado para gerenciamento de código e documentação do HomeLab.

## Motivo da escolha

- Leve
- Open Source
- Fácil backup
- Excelente integração com Docker
- Interface simples
- Compatível com GitHub
