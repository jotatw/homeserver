# Tipografia

Família padrão: `system-ui, -apple-system, "Segoe UI", Roboto, sans-serif`.

## Escala

| Papel | Tamanho | Peso | Uso |
|-------|---------|------|-----|
| Display | 1.3rem | 700 | Título de página / marca |
| Título grupo principal | 1.15rem | 700 | "Meu espaço" |
| Título grupo secundário | 0.95rem | 600 | "Aplicações", "Administração" |
| Título grupo técnico | 0.85rem | 500 | "Sistema" |
| Card - nome (ação) | 1.05rem | 600 | Título do card de ação |
| Card - descrição | 0.82rem | 400 | Subtítulo do card |
| Rótulo | 0.8rem | 600 | Cabeçalhos de tabela, labels |
| Metadados / rodapé | 0.75rem | 400 | Rodapé, versão, hints |

## Regras

- Grupos técnicos usam `text-transform: uppercase` com `letter-spacing`.
- Nunca misturar mais de 2 pesos por bloco visual.
- Texto de erro usa `danger-text` (`#f87171`) e ícone ⚠️.
- Estados vazios usam `text-muted` e ícone 📭.
