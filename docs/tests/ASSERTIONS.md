# Assertions

As assertivas são utilizadas para validar condições durante a execução dos testes.

Todas retornam:

0 → Sucesso

1 → Falha

Nenhuma assertiva imprime mensagens.

---

# Assertivas Gerais

## assert_true

Descrição

Valida se uma condição é verdadeira.

Retorno

0 ou 1

---

## assert_false

Descrição

Valida se uma condição é falsa.

---

## assert_equals

Descrição

Compara dois valores.

---

## assert_not_equals

Descrição

Compara dois valores diferentes.

---

# Arquivos

## assert_file_exists

Descrição

Verifica se um arquivo existe.

---

## assert_file_not_exists

Descrição

Verifica se um arquivo não existe.

---

# Diretórios

## assert_directory_exists

Descrição

Verifica se um diretório existe.

---

## assert_directory_not_exists

Descrição

Verifica se um diretório não existe.

---

# Variáveis

## assert_variable_set

Descrição

Verifica se uma variável possui valor.

---

## assert_variable_empty

Descrição

Verifica se uma variável está vazia.

# Sistema

Descrição
