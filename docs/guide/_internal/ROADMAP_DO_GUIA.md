# Roadmap do HomeServer Guide

## Objetivo

Este documento organiza o planejamento do HomeServer Guide.

Seu propósito é definir a estrutura da obra antes da escrita dos capítulos, garantindo que cada parte tenha um objetivo claro e que todo o conteúdo siga uma sequência lógica.

Este documento é utilizado apenas durante o desenvolvimento da documentação.
