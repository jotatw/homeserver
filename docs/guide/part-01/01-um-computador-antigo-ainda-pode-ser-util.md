# Capítulo 1 — Um computador antigo ainda pode ser útil?

## Contexto

Quando pensamos em montar um servidor doméstico, é comum imaginar equipamentos modernos, servidores dedicados ou computadores com alto desempenho.

Para muitas pessoas, essa ideia acaba se tornando uma barreira antes mesmo do projeto começar.

Mas será que um HomeServer realmente precisa de tudo isso?

Essa foi a pergunta que deu origem a este projeto.

---

## A ideia

Este guia nasceu da proposta de reutilizar um computador antigo e transformá-lo em uma plataforma doméstica útil, organizada e fácil de manter.

O objetivo nunca foi construir o servidor mais rápido ou executar o maior número possível de serviços.

A proposta sempre foi diferente:

**aproveitar o hardware disponível da melhor forma possível.**

Ao longo do projeto, ficou claro que planejamento, organização e simplicidade tiveram muito mais impacto no resultado final do que a capacidade do equipamento utilizado.

---

## A experiência deste projeto

O HomeServer apresentado neste guia foi desenvolvido utilizando um computador que, para muitas pessoas, já estaria aposentado.

Em vez de substituir o equipamento, a decisão foi entender seus limites e construir uma infraestrutura compatível com sua capacidade.

Essa escolha influenciou praticamente todas as decisões tomadas durante o desenvolvimento.

Os serviços foram escolhidos com cuidado.

A arquitetura foi mantida simples.

Os dados foram separados das aplicações.

Cada novo recurso foi adicionado apenas quando fazia sentido.

O resultado não foi um servidor cheio de funcionalidades, mas uma plataforma organizada, estável e preparada para evoluir.

---

## O que aprendemos

Uma das primeiras lições deste projeto foi perceber que um HomeServer não precisa ser grande para ser útil.

Muitas vezes, um ambiente simples atende perfeitamente às necessidades do dia a dia.

Mais importante do que instalar muitos serviços é compreender o problema que cada um deles resolve.

Essa forma de pensar tornou o projeto mais fácil de manter, documentar e expandir.

---

## Antes de continuar

Este guia não pretende convencer ninguém a utilizar o mesmo hardware, os mesmos programas ou a mesma arquitetura.

Cada ambiente possui necessidades diferentes.

O objetivo é compartilhar uma experiência real, mostrando as decisões tomadas ao longo do desenvolvimento para que elas possam servir como inspiração para outros projetos.

Nos próximos capítulos começaremos a explorar como essa ideia foi transformada, passo a passo, em uma infraestrutura doméstica funcional.
